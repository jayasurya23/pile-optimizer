# ADR-NNNN: Short title of the decision

| | |
|---|---|
| **Status** | Proposed / Accepted / Deprecated / Superseded by ADR-NNNN |
| **Date** | YYYY-MM-DD (the date the decision was taken) |
| **Recorded** | YYYY-MM-DD |

## Context

What is the situation that forces a decision? State the facts, constraints and
forces at play (technical, organisational, cost). Link to evidence.

## Decision

What did we decide? Write it in full sentences, in the active voice
("We will ...", or describe what the system now does).

## Options considered

The alternatives that were genuinely weighed, and why each was accepted or
rejected. If none were recorded, say so. Do not invent alternatives.

## Consequences

**Positive**

- What gets better.

**Negative or to watch**

- What it costs, what gets harder, what must be revisited if circumstances change.

## Evidence

- `path/to/file`: what it shows.
- Commit `abc1234`: what it records.
